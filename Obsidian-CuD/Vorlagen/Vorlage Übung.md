# Arbeitsblatt für eine neue Aufgabe

Anleitung: [[31 Neue Übung hinzufügen]]. Vorlage kopieren und Auftrag, Test und Lösung getrennt erarbeiten.

| Feld | Ausfüllen |
| --- | --- |
| Quelle oder eigene Ergänzung | Blattkennung, Datei und PDF-Seite |
| Aufgaben-ID und Originalnummer | Über mehrere Blätter eindeutig |
| Ziel und Voraussetzungen | Vorhandene Wissensbausteine |
| Eingaben | Datei, Datenformat, Einheit und Herkunft |
| Erwartetes Verhalten | Unabhängig hergeleitet |
| Grenzfälle | Leerfall, Fehler und relevante Grenzen |
| Testzuordnung | Welche Prüfung führt exakt diese Lösung aus? |

## Auftrag

Kurze Aufgabe ohne vorweggenommene Lösung formulieren. Dann Schritte, kleinsten Hinweis, weiterführenden Hinweis und Selbstkontrolle schreiben. Die Musterlösung getrennt ablegen und ihre Annahmen erklären.

## Abnahme

- [ ] Quelle oder eigene Herkunft klar benannt.
- [ ] ID und Blattnummer eindeutig verknüpft.
- [ ] Test vor beziehungsweise unabhängig von der Musterlösung entworfen.
- [ ] Sichtbarer Download entspricht der Testdatei.
- [ ] Hauptaufruf der Kopierlösung tatsächlich ausführbar.
- [ ] Fehlende Originaldaten nicht als synthetische Originale ersetzt.
- [ ] Abdeckung, Voraussetzungen und Suchverhalten aktualisiert.
