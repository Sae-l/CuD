# Arbeitsblatt für eine begrenzte Übernahme

Ablauf: [[32 Entwicklung und Release]]. Sichtbarkeit: [[43 Sichtbarkeit für Besucher]]. Dieses Blatt ist eine Vorlage und keine bereits erteilte Freigabe.

| Gegenstand | Ergebnis eintragen |
| --- | --- |
| Änderung und Ziel | Konkretes sichtbares Verhalten |
| Commit, Branch und Remote | Tatsächlich bearbeiteter Stand |
| Geänderte Dateien | Geprüfter Diff |

| Fachliche Tests | Ausgeführte Befehle und Resultate |

## Vor der Übernahme

- [ ] Zweck und Dateiumfang stimmen überein.
- [ ] Keine Zugangsdaten oder persönlichen Rohbeobachtungen im Paket.
- [ ] Fachliche Annahmen und fehlende Daten sichtbar.
- [ ] Softwaretests am tatsächlich vorgesehenen Stand bestanden.
- [ ] Rechte und beabsichtigte Sichtbarkeit getrennt beurteilt.
- [ ] Keine behauptete Geräte- oder Lernabnahme ohne entsprechende Belege.
